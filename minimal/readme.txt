Minimal is a one-column WordPress block theme for personal notes and long-form
writing. It uses a warm paper palette, a readable serif for article text, and
Special Elite for titles and small editorial details.

== Setup ==

1. Activate Minimal under Appearance > Themes.
2. Set the site title and tagline under Settings > General or in the Site Editor.
3. Edit the Header template part in Appearance > Editor to create the navigation.
4. Write posts with ordinary WordPress blocks. No companion plugin is required.

== Images and video ==

Featured images and Image, Gallery, Video, and Cover blocks are styled by the
theme. To add YouTube, paste the video URL on its own line in the editor or add a
YouTube Embed block. The theme gives video embeds a responsive 16:9 frame.

== Typography and paper effect ==

Special Elite is loaded from Google Fonts. If that request is blocked, the theme
falls back to Courier New or Courier. Long article text always uses the Reading
Serif stack defined in theme.json.

The paper colors and editor font choices live in theme.json. The subtle CSS paper
layers are grouped near the body rule in style.css so their intensity can be
changed without affecting the layout.

== Privacy and performance ==

The theme contains no JavaScript, analytics, tracking, or third-party libraries.
It makes one external stylesheet request to Google Fonts for Special Elite.
